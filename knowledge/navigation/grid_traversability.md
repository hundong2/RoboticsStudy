# 높이 격자 기반 통과성 추정

## 최소 모델

높이 격자 `z(x,y)`에서 중앙차분으로 표면 기울기를 구한다.

```text
g_x = (z[x+1,y] - z[x-1,y]) / (2r)
g_y = (z[x,y+1] - z[x,y-1]) / (2r)
theta = atan(sqrt(g_x^2 + g_y^2))
```

주변 높이의 표준편차는 작은 요철을 나타내는 간단한 거칠기 특징이다. 두 특징을 로봇 허용 한계로 정규화하고 `[0,100]`에 clamp하면 설명 가능한 비용층을 얻는다.

## 실무에서 추가할 것

- IMU/TF로 높이축과 중력축 정렬
- footprint 내부 최대 경사와 step height
- 센서 분산·관측 거리·가림에 따른 confidence
- 바퀴/궤도/다리별 접촉 및 미끄럼 모델
- 시간 필터와 동적 장애물 분리

## 위험한 오해

`nav_msgs/OccupancyGrid`에 값을 담았다고 해서 곧바로 점유 확률이 되는 것은 아니다. 통과성 비용을 넣을 경우 frame, 값 의미, unknown 처리, planner 변환 계약을 별도로 문서화해야 한다.
