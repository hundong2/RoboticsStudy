# 임피던스 제어 핵심 노트

## 목적

임피던스 제어는 접촉점에서 위치나 힘 하나를 직접 강제하기보다, 외력과 운동 사이의 원하는 동적 관계를 만든다. 대표 목표는 `F = M_d e_ddot + D_d e_dot + K_d e`이다.

## 튜닝 직관

- `K_d` 증가: 위치 오차 감소, 접촉력/충격과 요구 대역폭 증가.
- `D_d` 증가: 진동 감소, 응답 둔화와 큰 속도 오차 힘 증가.
- `M_d` 증가: 무겁게 반응, 가속도 감소. 실제 관성/토크 한계와 구현 가능성을 확인해야 한다.
- 1축 2차계의 시작점은 `D_d = 2*zeta*sqrt(M_d*K_d)`이며, 접촉 환경 강성까지 포함한 폐루프에서 다시 검증한다.

## impedance와 admittance

- impedance: 운동을 입력으로 보고 힘을 출력한다. 토크/힘 제어 가능한 로봇에 자연스럽다.
- admittance: 힘을 입력으로 보고 목표 운동을 출력한다. 강한 내장 위치 서보 위에 외력 순응을 얹을 때 흔하다.
- 이름보다 중요한 것은 센서-연산-액추에이터의 실제 인과성과 에너지 흐름이다.

## 구현 체크리스트

1. 작업 좌표계와 힘 센서 좌표계를 명시한다.
2. 포화 전후의 안정성과 anti-windup/energy tank를 검토한다.
3. 지연, 표본화, 필터 위상 지연을 포함해 안정 여유를 측정한다.
4. Jacobian 특이점과 관절 한계를 별도로 처리한다.
5. 제어기와 독립된 힘/속도/에너지 안전 감시 및 하드웨어 정지 경로를 둔다.
