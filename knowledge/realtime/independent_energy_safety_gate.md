# 독립 에너지 안전 게이트 패턴

## 구조

제어기의 원시 명령을 액추에이터에 직접 연결하지 않는다. 별도 감독기가 명령 값, 샘플 나이, 센서 힘, 에너지 수지를 검사하고 **허용 명령**만 발행한다. 액추에이터는 허용 Topic/공유 메모리만 읽는다.

```text
controller -> raw command -> safety gate -> allowed command -> actuator
                               ^
                               +-- independent sensors/watchdogs
```

## 왜 히스테리시스가 필요한가

한 샘플 임계값만으로 정지하면 잡음에 민감하고, 임계값 아래로 잠깐 내려왔을 때 즉시 복구하면 stop/run 채터링이 생긴다. 연속 위반 수, 최소 정지 시간, 연속 정상 수를 서로 다른 조건으로 둔다.

## 에너지 수지

수동 시스템의 기본 검사는 저장 에너지 증가가 외부 공급 에너지에서 소산 에너지를 뺀 값보다 크지 않은지 보는 것이다.

```text
E(t)-E(0) <= integral(input * velocity) dt - dissipated_energy
```

양의 residual은 모델 밖 에너지 생성, 시각 불일치, 누락된 입력, 수치 오차 중 하나를 뜻할 수 있다. 따라서 residual은 진단 신호이지 단독 안전 인증이 아니다.

## 실시간 구현 원칙

- hot path에는 고정 크기 데이터와 상한이 알려진 연산만 둔다.
- 문자열/로그/파일/DDS 진단 직렬화는 저주기 경계로 분리한다.
- watchdog은 발행 시각이 아니라 측정/명령 생성 시각의 age를 검사한다.
- 감독기 자체가 죽었을 때 액추에이터가 마지막 명령을 유지하지 않도록 로컬 timeout과 fail-silent 기본값을 둔다.
- 소프트웨어 게이트는 하드웨어 STO를 대체하지 않는다.
