# Kelvin-Voigt 접촉 모델

Kelvin-Voigt 모델은 스프링과 댐퍼를 병렬로 놓아 접촉 반력을 `F = -K x_pen - D v_pen`으로 표현한다. 계산이 싸고 직관적이어서 제어 입문 시뮬레이션에 유용하다.

## unilateral 접촉

벽은 로봇을 밀 수 있지만 당기지 못한다. 따라서 침투량 `x_pen = max(0, x-x_wall)`을 쓰고, 분리 방향에서 인장력이 생기지 않도록 접촉력을 압축 방향으로 제한한다.

```text
x_pen = max(0, x - x_wall)
F_env = x_pen > 0 ? min(0, -K*x_pen - D*v) : 0
```

## 수치 적분

강성이 커질수록 가장 빠른 고유진동수가 올라가고 필요한 적분 주기는 짧아진다. 단순 explicit Euler는 수치 에너지를 만들 수 있으므로, 최소한 semi-implicit Euler를 쓰고 시간 간격 변화와 에너지 drift를 계측한다.

## 한계

- 실제 접촉의 마찰, 충격, 히스테리시스, 소성 변형을 표현하지 못한다.
- penetration은 수치 모델의 상태이지 실제 강체가 관통한다는 뜻이 아니다.
- 시뮬레이션에서 안정한 게인은 실제 센서 지연·구조 유연성·기어 백래시에서 불안정할 수 있다.
