# 논문 리뷰 — Besl & McKay, “A Method for Registration of 3-D Shapes”

## 서지 정보

- Paul J. Besl, Neil D. McKay
- *IEEE Transactions on Pattern Analysis and Machine Intelligence*, 14(2), 239–256, 1992
- DOI: [10.1109/34.121791](https://doi.org/10.1109/34.121791)
- 선정 이유: 최신 논문 대신 scan matching과 3D registration의 출발점이 된 근간 논문을 골랐다. 오늘 실습은 이 논문의 ICP 구조를 2D 연속 라이다에 축소 적용한다.

## 1. 해결하려는 문제

센서가 얻은 점/곡선/표면은 센서 좌표계에 있고, 기준 모델은 다른 좌표계에 있다. 두 형상이 같은 물체를 나타내는지 확인하거나 여러 관측을 하나의 지도로 합치려면, 한 형상을 다른 형상에 가장 잘 맞추는 강체 변환 \((R,t)\)를 찾아야 한다.

문제는 두 데이터 사이의 점 대응을 미리 모른다는 데 있다. 대응을 안다면 최소제곱 강체 정합을 풀 수 있지만, 정합 변환을 모르면 어떤 점이 서로 대응하는지도 모른다. 즉 **대응과 자세가 서로를 필요로 하는 순환 문제**다.

로보틱스에서는 같은 문제가 다음 형태로 반복된다.

- 연속 라이다 scan의 상대 자세 추정
- RGB-D/3D lidar point cloud 정합
- 로컬 맵과 현재 scan의 localization
- CAD 모델과 실제 부품의 검사·조립 정렬

## 2. 핵심 아이디어와 수학적 직관

ICP(Iterative Closest Point)의 핵심은 순환 문제를 두 개의 쉬운 단계로 번갈아 푸는 것이다.

1. 현재 변환으로 데이터 형상을 옮긴다.
2. 옮겨진 각 점에 대해 모델 형상의 최근접점을 대응으로 선택한다.
3. 그 대응을 고정하고 평균제곱거리를 최소화하는 강체 변환을 계산한다.
4. 오차 감소가 충분히 작아질 때까지 반복한다.

점 집합 버전의 목적함수는 다음과 같다.

\[
E(R,t)=\frac{1}{N}\sum_{i=1}^{N}\left\|p_i-(Rq_i+t)\right\|^2
\]

여기서 \(q_i\)는 움직일 데이터 점, \(p_i\)는 현재 선택된 모델 대응점이다. 2D에서는 두 점군의 중심을 빼 translation을 제거한 뒤, 교차항으로 회전각을 구하고 \(t=\bar p-R\bar q\)로 이동을 복원할 수 있다. 3D 원 논문은 여러 형상 표현에 공통으로 적용 가능한 최근접점 연산과 강체 정합의 반복 구조를 제시한다.

직관적으로는 “가장 가까워 보이는 짝을 임시 정답으로 놓고, 그 짝들이 더 가까워지는 자세를 찾는다”를 반복한다. 각 반복의 대응·정합 단계는 현재 평균제곱 오차를 증가시키지 않는 방향으로 진행하므로 오차는 단조 감소한다. 그러나 이는 **가까운 지역 최솟값으로의 수렴**이지, 임의의 초기 자세에서 전역 최적 정합을 보장한다는 뜻은 아니다.

오늘 코드와의 연결은 다음과 같다.

- `scan_to_points()`: LaserScan 극좌표를 Cartesian 점군으로 변환
- 최근접점 이중 루프: 논문의 대응 단계
- `atan2(sine_term, cosine_term)`: 2D 최소제곱 회전
- `previous_centroid - R * current_centroid`: 최소제곱 translation
- 최대 8회와 변화량 임계값: 계산 시간과 수렴을 제한하는 종료 조건
- RMSE: 논문의 평균제곱 거리 계열 품질 지표

## 3. 실무 적용 가능성과 한계

### 적용 가능한 지점

- 좋은 초기 자세가 있는 lidar odometry의 frame-to-frame 정합
- feature 추출 없이 기하 자체를 활용하는 정밀 registration
- scan-to-map 최적화의 baseline 또는 회귀 테스트 oracle
- 작은 point cloud에서 구현이 단순하고 동작을 설명하기 쉬운 교육/프로토타입

### 반드시 기억할 한계

1. **초기값 민감도**: 이동/회전이 크면 최근접점이 잘못 연결되어 다른 지역 최솟값으로 간다. wheel odometry, IMU, coarse registration이 초기값을 제공해야 한다.
2. **대칭과 퇴화**: 긴 평면 하나나 대칭 방에서는 일부 이동·회전을 구분하기 어렵다. Hessian/공분산의 조건과 장면 기하를 봐야 한다.
3. **동적 물체와 outlier**: 사람·차량·반사 잡음이 최근접점 대응을 오염시킨다. 거리/법선 gate, trimmed ICP, 강건 손실이 필요하다.
4. **계산량**: 오늘의 전수 최근접점은 \(O(N^2)\)다. 큰 point cloud에서는 kd-tree, voxel grid, 병렬화가 필요하다.
5. **오차 모델**: point-to-point 거리는 표면 접선 방향의 불필요한 제약이 커 수렴이 느릴 수 있다. 법선이 신뢰 가능하면 point-to-plane이 자주 더 효율적이다.
6. **RT 보장 부재**: 고정 반복만으로 전체 노드의 WCET가 보장되지는 않는다. 입력 상한, 최근접점 자료구조, 메시지 할당, 캐시와 DDS까지 측정해야 한다.

## 엔지니어 관점 결론

이 논문의 가장 오래가는 가치는 특정 3D 공식을 넘어 **대응을 갱신하고 변환을 다시 푸는 반복 구조**를 명료하게 만든 데 있다. 오늘의 2D 구현은 그 구조를 직접 볼 수 있지만 제품용 SLAM front-end는 아니다. 다음 단계는 odometry/IMU 초기값, outlier rejection, point-to-line 오차, 누적 pose graph와 loop closure를 더하고, 각 단계의 지연·실패 모드를 계측하는 것이다.
