# 6. I2S 및 기타 핀 신호

## 6.1 I2S

I2S는 PCM 오디오를 위한 동기식 직렬 인터페이스다.

| J12 | 신호 | 의미 |
|---:|---|---|
| 12 | I2S0_SCLK | bit clock |
| 35 | I2S0_FS | left/right 또는 frame select |
| 38 | I2S0_DIN | Jetson 입력 |
| 40 | I2S0_DOUT | Jetson 출력 |

master/slave, sample rate, sample width, channel 수, I2S/left-justified/DSP format이 양쪽에서 일치해야 한다. Jetson-IO로 I2S pinmux를 설정한 뒤 ALSA ASoC card와 codec driver/device tree 구성이 필요하다. 단순 파일 `open()`만으로 I2S 핀을 직접 다루지 않는다.

```bash
aplay -l
arecord -l
cat /proc/asound/cards
sudo /opt/nvidia/jetson-io/config-by-function.py -l enabled
```

실무에서는 codec의 MCLK 요구, 전원 sequence, reset GPIO, DAI link와 mixer route까지 확인한다. 핀만 연결해도 소리가 나는 인터페이스가 아니다.

## 6.2 active-low 제어 신호

`CS*`, `RTS*`, `CTS*`, `RESET_N`, `PWDN`처럼 Low가 활성인 신호가 있다. 문서의 별표가 곱셈 기호가 아니라 active-low 표시인지 문맥을 확인한다. reset을 GPIO로 제어할 때 boot 초기 pull 상태가 장치를 의도치 않게 reset 해제하지 않는지 측정한다.

## 6.3 clock과 frame

- UART는 별도 clock 없이 양쪽 baud를 맞춘다.
- I2C·SPI·I2S는 controller가 clock을 공급하는 동기식 인터페이스다.
- PWM은 데이터 protocol이 아니라 반복 pulse의 시간 비율이다.
- CSI/PCIe/USB/DisplayPort 같은 고속 차동 신호는 J12 저속 GPIO 실습 방식으로 취급하지 않는다.

## 6.4 Vision/VLA 시스템 연결

- I2C: IMU, 거리 센서, 조명 controller의 설정과 telemetry
- UART: GNSS, MCU, motor controller의 command/feedback
- SPI: 고속 ADC, encoder interface, 보조 MCU
- GPIO: trigger, fault, enable, emergency-state 입력
- PWM: 조명 밝기나 fan/servo controller의 command 입력
- CAN: distributed actuator와 safety controller
- I2S: microphone array 또는 경보 audio

센서 데이터를 VLA 입력으로 쓰더라도 low-level I/O process와 AI inference process를 분리한다. I/O process는 timestamp, CRC, timeout, validity를 제공하고, AI 계층은 유효성이 확인된 message만 소비하게 한다.
