# 공식 문서 목록과 한국어 해설 범위

기준일: 2026-08-29. 링크의 `latest` 문서는 이후 변경될 수 있으므로, 제품 기준선에서는 열람일과 버전을 함께 기록한다.

## A. 개발키트와 설치

1. [Jetson Orin Nano Developer Kit User Guide](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/)
   - 한국어 반영: 제품 정체성, 성능, 구성, 설치 문서 구조.
2. [Quick Start - JetPack 7.2.1](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/quick_start.html)
   - 반영: Jetson ISO, 대상 storage, firmware gate, 첫 부팅.
3. [BSP Setup](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/setup_bsp.html)
   - 반영: ISO, SDK Manager, flash script, RCM.
4. [JetPack 6.x Update Path](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/update_firmware.html)
   - 반영: 구형 QSPI/UEFI 업데이트 필요성.
5. [Docker Setup](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/setup_docker.html)
   - 반영: NVIDIA container runtime, Docker 검증.
6. [CUDA Setup](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/setup_cuda.html)
   - 반영: host/컨테이너 CUDA 선택.
7. [JetPack SDK Setup](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/setup_jetpack.html)
   - 반영: `nvidia-jetpack` 패키지, 버전 확인.
8. [JetPack SDK Downloads and Notes](https://developer.nvidia.com/embedded/jetpack/downloads)
   - 기준선: JetPack 7.2.1, L4T 39.2.1, CUDA 13.2.1, TensorRT 10.16.2.

## B. 하드웨어와 핀

9. [Hardware Layout](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/hardware_layout.html)
   - 반영: 포트 위치·역할, DP, USB-C, NVMe, CSI.
10. [How-to Guides](https://docs.nvidia.com/jetson/orin-nano-devkit/user-guide/latest/howto.html)
    - 반영: 전원 종료, power mode, tegrastats, CSI 연결, RCM.
11. [Carrier Board Specification PDF](https://developer.nvidia.com/downloads/assets/embedded/secure/jetson/orin_nano/docs/jetson_orin_nano_devkit_carrier_board_specification_sp.pdf)
    - 반영: J12 40핀 전체 기본 기능, J14 전체, 카메라·팬·CAN·RTC·전원 주의사항.
12. [Jetson Orin NX/Nano Design Guide](https://developer.nvidia.com/downloads/jetson-orin-nx-series-nano-series-design-guide)
    - 반영: 커스텀 캐리어보드 설계 검토 체계.
13. [Jetson Download Center](https://developer.nvidia.com/embedded/downloads)
    - 검색 대상: Pinmux template, Data Sheet, Thermal Design Guide, reference design files, supported components.

17. [Module Adaptation and Bring-Up](https://docs.nvidia.com/jetson/archives/r39.2/DeveloperGuide/HR/JetsonModuleAdaptationAndBringUp.html)
    - 반영: hardware/software bring-up checklist.

19. [Configuring Expansion Headers](https://docs.nvidia.com/jetson/archives/r39.2/DeveloperGuide/HR/ConfiguringTheJetsonExpansionHeaders.html)
    - 반영: Jetson-IO와 DTBO.
20. [Platform Power and Performance](https://docs.nvidia.com/jetson/archives/r39.2/DeveloperGuide/SD/PlatformPowerAndPerformance/JetsonOrinNanoSeriesJetsonOrinNxSeriesAndJetsonAgxOrinSeries.html)

23. [Camera Software Development Solution](https://docs.nvidia.com/jetson/archives/r39.2/DeveloperGuide/SD/CameraDevelopment/ArgusFramework/CameraSoftwareDevelopmentSolution.html)
    - 반영: libargus, `nvarguscamerasrc`, V4L2 API matrix.
24. [Sensor Software Driver Programming](https://docs.nvidia.com/jetson/archives/r39.2/DeveloperGuide/SD/CameraDevelopment/ArgusFramework/SensorSoftwareDriverProgramming.html)

25. [Jetson Linux Multimedia](https://docs.nvidia.com/jetson/archives/r39.2/DeveloperGuide/SD/Multimedia.html)

26. [VPI 4.1 Getting Started](https://docs.nvidia.com/vpi/getting_started.html)

## 문서 사용 규칙

- 하드웨어 절대 정격과 pin electrical limits: Carrier Board Specification/Data Sheet 원문 우선.
- BSP 명령: 설치된 L4T와 동일한 archive 버전 문서 우선.
- `latest` AI 문서: JetPack에 실제 포함된 TensorRT/VPI 버전과 support matrix 우선.
- 블로그: 아키텍처와 모델 후보 참고용이며 제품 요구사항의 최종 근거로 사용하지 않는다.
